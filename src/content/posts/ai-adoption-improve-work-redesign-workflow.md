## 做了 HR 知識助手和 GenBI，然後呢？

我做過不少 AI Agent 和 Workflow，包含 HR 知識助手與 GenBI。

HR 知識助手用 RAG，從人資文件裡找資料來回答問題。GenBI 則用 Text2SQL，讓不會寫 SQL 的人，也能用日常語言自己查資料。

做這些助手，目的很直接：少花一點時間找資料，少一點重複工作。但做著做著，我也開始想，資料查出來之後呢？

像 GenBI，使用者可能拿數據整理報表，再交給主管；也可能繼續追問，往下探索。前者讓原本的工作更快完成，後者則有機會讓人問出以前因為不會查資料，而沒有繼續問下去的問題。

這也呼應我在企業裡看到的兩種期待：有人想讓 AI 接手自己不想做的事，有人想試試以前成本太高、做不到的事。這兩種期待會出現在同一個工具裡。

自動化早就有了，n8n 和 RPA 都能處理不少重複作業。AI 加進來之後，我更在意它能讓使用者多做到什麼。

以我自己的經驗來說，用 AI 省下時間後，我並沒有因此做更多工作。如果用完成的工作量來看，生產力並沒有增加多少，最直接的好處就是省下時間。這也讓我想繼續看，這些改變有沒有讓團隊多完成什麼。

## 員工交得快，主管還是只有一個

[大人學 EP715](https://www.youtube.com/watch?v=8VSCpBCqdO4) 談到一個情境：員工用 AI 省下了幾天工時，提案交出去，卻還要等主管下週才有空看。當大家交得更快、更多，主管還得花時間看完、找問題、退件。

所以，就算員工真的把省下的時間拿來做更多工作，也可能只是讓主管桌上多堆幾份提案。

大人學的 Joe 建議，把資深主管腦中的判斷標準整理出來，讓團隊能在交件前搭配 AI 檢查，減少來回修改。

這讓我想到，可以把這些標準寫成 skill，也就是 Agent 執行工作時可以使用的指示與參考資料。員工整理自己熟悉的操作步驟，主管整理審核標準：哪些資料一定要有、哪些條件不符合就退回、哪些情況需要人來決定。

這是我從節目延伸的想法。能先檢查的就先做，主管再處理需要取捨的部分。標準也要跟著實際結果調整，看看有沒有漏掉問題。

[科技浪 EP160](https://podcasts.apple.com/tw/podcast/ep160-ai-%E6%99%82%E4%BB%A3%E7%9A%84%E5%85%AC%E5%8F%B8%E5%B0%87%E5%BE%B9%E5%BA%95%E6%94%B9%E8%AE%8A-%E4%B8%80%E5%80%8B%E4%BA%BA%E5%A6%82%E4%BD%95%E5%89%B5%E9%80%A0%E7%99%BE%E5%80%8D%E5%83%B9%E5%80%BC-anthropic-spacexai/id1702409419?i=1000797196029) 也談到信任 Agent 的問題。主持人哈利轉述 Lauren Tan 的分享：她單月能交付數千個 PR，也就是程式碼變更提案；團隊裡連 PM、設計師也能透過 Agent 參與正式功能開發。

哈利提到，Lauren Tan 花力氣整理程式碼、清理不良做法，再加上自動檢查規則、skill 和驗證機制，建立讓團隊能放心使用 Agent 的工作環境。這讓我覺得，除了把工作交出去，還得把 Agent 做事的環境顧好。

套回 HR 知識助手和 GenBI，我也想回頭檢查：文件和資料定義是否清楚？回答與查詢結果要怎麼驗證？這些做好了，才有機會減少每次都要人盯著的部分。

## 工具變了，工作方式也能一起改

[ihower／愛好 AI 工程 Blog 的文章](https://blog.aihao.tw/2026/05/31/cedric-chin-sensemaking-ai/)提到 Walmart 當年導入電腦的案例。文章說明，Walmart 透過即時資料共享，讓門市與供應商能依據庫存資訊做決策，改變補貨與協作方式。

這個例子讓我想到，資訊變得容易取得之後，分工也可以跟著改。

回頭看 GenBI，讓不會寫 SQL 的人自己查資料，已經跨過一個門檻。但查到資料以後，哪些事能自己處理，哪些還是得等主管？這一段也需要一起看。

最近聽到[企業流程再造](https://zh.wikipedia.org/zh-tw/企业流程再造)的概念：從想達成的成果出發，重新設計整套工作方式。套到我自己的工作，就是把流程攤開：哪些步驟可以省掉？哪些檢查能提早做？哪些事情可以授權，讓工作直接往下走？

我想像未來的公司裡，可能有上百、上千個 Agent，接手我們現在做的許多工作。如果它們做完每件事，都還要等同一個主管批准，今天的瓶頸只會更嚴重。

所以，除了把工作寫成 skill，還得安排好 Agent 怎麼交接、什麼時候找人，以及出了問題由誰處理。這些都需要人先想清楚。

## 人的時間，要拿來做什麼？

我希望把能自動化的工作交給 Agent，讓人有時間專注在 **Agent 還沒辦法代替我們做的事，尤其是溝通**。

跨部門合作時，資料整理好了，對方也不一定願意配合。每個部門都有自己的目標和優先順序，你得了解對方在意什麼，說明這件事為什麼值得做，再想辦法**說服對方投入時間和資源**。這些事情，還是得自己出面談。

往上跟主管爭取支持，往下跟團隊說明方向，也是一樣。Agent 可以幫忙準備資料、整理說法，但實際面對對方的疑慮、協調彼此能接受的做法，仍然需要人花時間。

Agent 可以幫忙分析選項、整理利弊，但最後要怎麼選、願意放棄什麼、承擔什麼風險，還是得由我們決定。結果也要自己負責，這些取捨沒辦法一起交給 Agent。

回頭看 HR 知識助手和 GenBI，我會期待它們幫人省下查文件、查資料的時間，讓人有餘力帶著這些資訊去討論問題、推動事情。這也是我接下來想繼續想的：助手把工作做完之後，人要怎麼接著往下做？

> 把能自動化的工作交給 Agent，把人的時間留給溝通、協調和說服，以及做出決定、承擔結果。
